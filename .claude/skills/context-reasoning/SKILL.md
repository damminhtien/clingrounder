# Context Reasoning

Use this skill for assertion status and clinical context logic.

## Scope

- Maintain negation, historical, family-history, possible, conditional, planned, and resolved rules.
- Use sentence and section scope conservatively.
- Add focused examples for Vietnamese/English clinical phrasing.

## Guardrails

- Negated diseases are not confirmed patient conditions.
- Family-history diseases are not patient-present conditions.
- Do not collapse `POSSIBLE`, `HISTORICAL`, `PLANNED`, or `RESOLVED` into `PRESENT`.
