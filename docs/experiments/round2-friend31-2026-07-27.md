## What Changed

The artifact's main gain is entity recall rather than a metadata convention. Relative to our
28.9092 baseline:

```text

friend-only entities: 1210
our-only entities: 569
overlapping disagreements: 246
```

The bundled reviewer uses a local Qwen3.5-9B model, asks for missing entities one line at a time,
repeats until no additions remain, propagates a recognized mention to other exact occurrences, and
then resolves overlaps. Its implementation uses first-occurrence projection in one stage, so the
logic is evidence rather than trusted runtime code.

The repository implementation keeps the useful protocol while enforcing stricter invariants:

- the model returns exact quotes and types, never offsets;
- every still-unlabeled occurrence is projected locally;
- thresholds are applied per entity type;
- the baseline wins every overlap in the recall-only probe;
- baseline assertion/candidate lists remain unchanged;
- raw responses, hashes, rejections, and per-document counters are logged.

### Extraction Adapter Diagnosis

The first full extraction attempt was stopped after eight documents because every consensus file
was empty. A one-document diagnostic run showed that Qwen generated useful exact quotes, but the
adapter discarded them for two implementation reasons:

1. The JSON schema example contained `confidence: 0.0`, which Qwen copied. Per-type thresholds then
   rejected every otherwise valid quote.
2. Qwen sometimes returned a whole clause as optional context. Context longer than 120 characters
   caused the complete proposal to be rejected.

Commit `b2fed317b6f65dfb166a3fe8fff5ecfdfe62485b` fixes the adapter:

- model self-confidence is removed from extraction prompts;
- an exact quote receives deterministic source score `0.90`;
- independent pass/support agreement remains the promotion gate;
- overlong context keeps only the 120 characters nearest the quote;
- bad context falls back to every exact occurrence, preserving raw offsets.
